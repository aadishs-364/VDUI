# Contributing

This is a personal design portfolio, so code changes aren't expected — but feedback is very welcome.

## Giving feedback
- Spotted a chart that could be clearer, more accessible or more honest? Open an issue with the **Design feedback** template and mention the case study and chart.
- Found a broken link or image? Use the **Bug report** template.

## If you do open a pull request
- Keep it to one focused change and fill in the pull request template.
- Don't commit datasets (`*.csv`) — the notebooks keep their outputs, and the data stays at its original source.

By taking part, you agree to follow the [Code of Conduct](CODE_OF_CONDUCT.md).
